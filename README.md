# AI Credit Risk & Loan Default Intelligence Platform

Decision-support platform for lending risk assessment. Given an applicant and
their historical financial information, the system estimates default
probability, ranks risk, explains the strongest drivers, and produces a
decision-support report. **This system is not a replacement for a human
credit officer.**

## Quickstart

### 1. Get the data
Either run locally:
```bash
pip install kaggle --break-system-packages
# place kaggle.json in ~/.kaggle/ first (see download_data.py docstring)
python download_data.py
```
...or, inside the notebook (Colab), use the built-in Kaggle API cell in
Section 0.

### 2. Run the notebook
Open `notebooks/01_credit_risk_full_pipeline.ipynb` in Google Colab or
Jupyter and run all cells top to bottom. It will:
- Load and explore the data (SQL + EDA)
- Engineer features from bureau / previous applications / installments / etc.
- Train Logistic Regression → Decision Tree → Random Forest → XGBoost
- Tune the best classical model and pick a business-cost-optimal threshold
- Train an MLP (deep learning upgrade) and compare it to the classical models
- Generate SHAP explanations
- Save `models/credit_risk_pipeline.joblib` and `models/metadata.json`

### 3. Run the app
```bash
pip install -r requirements.txt
streamlit run app/app.py
```

### 4. Run with Docker
```bash
docker build -t credit-risk-app .
docker run -p 8501:8501 credit-risk-app
```

### 5. Run tests
```bash
pytest tests/
```

## Dataset

[Home Credit Default Risk (Kaggle)](https://www.kaggle.com/competitions/home-credit-default-risk/data)
— multi-table credit data suitable for joins, feature engineering, and risk
modeling.

## Evaluation Metrics

Primary metrics: PR-AUC, ROC-AUC, Recall, Precision, F1, Calibration/Brier
score. The decision threshold is chosen via a business cost matrix
(cost of a missed default vs. cost of a wrongly rejected applicant), not a
fixed 0.5 cutoff.

## Responsible AI Notes

- No target leakage: supplementary tables only contain information available
  *prior to* the current loan decision.
- Fairness analysis is performed across demographic/proxy groups where
  ethically appropriate (see the notebook's explainability section).
- The model is a decision-support tool; final lending decisions require human
  review.
